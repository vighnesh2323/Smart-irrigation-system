# Smart Irrigation System

An IoT-based irrigation system developed to improve water efficiency by automating irrigation based on real-time sensor data.

## Project Overview
The Smart Irrigation System monitors soil moisture levels and controls water supply automatically.  
The objective of the project is to reduce water wastage and enable efficient irrigation using embedded systems and IoT concepts.

## System Architecture
The system consists of a microcontroller interfaced with soil moisture sensors and a water pump through a relay module.  
Based on the sensor readings and predefined threshold values, the controller activates or deactivates the irrigation process.

## Hardware Components
- ESP32 / Arduino microcontroller  
- Soil moisture sensor  
- Relay module  
- Water pump  
- Power supply unit  

## Software and Technologies
- Embedded C  
- ESP32 / Arduino platform  
- IoT fundamentals  
- Sensor interfacing  

## Key Features
- Automatic irrigation control based on soil conditions  
- Reduced manual intervention  
- Improved water usage efficiency  
- Scalable for small and medium-scale applications  

## Applications
- Agricultural irrigation systems  
- Home and community gardens  
- Smart farming applications
